# em-ifs-session — first-run setup

The `/em-ifs-session` skill hard-refuses on the first invocation if the Obsidian-side scaffolding isn't in place. This is deliberate: the safety fallback (`Crisis Plan.md`) must be user-authored in a non-crisis moment, not generated by the skill. This doc walks you through the one-time setup so the next invocation runs cleanly.

If you're hitting one of the refusal errors below, scroll to the matching section.

## What you need

Three files inside your Obsidian vault, under `<vault>/6 - Full Notes/IFS/`:

| File             | Purpose                                                                                | Author     |
| ---------------- | -------------------------------------------------------------------------------------- | ---------- |
| `IFS.md`         | Homepage. Carries the `crisis_fallback:` pointer in frontmatter.                       | You        |
| `Crisis Plan.md` | Concrete self-regulation protocol the skill links to on a crisis-pattern match.        | You        |
| `Trailheads.md`  | Optional. Flat dated list of unworked entry points. Skill treats missing as empty.     | You        |

The `Sessions/` and `Parts/` folders are auto-created by the skill on first run — don't pre-create them.

The vault root path (`/home/michael/My Vault/`) and the `6 - Full Notes/IFS/` subpath are pinned in `../ifs-shared/OBSIDIAN.md`. **If your vault lives elsewhere**, update the `## Vault root` and `## Folder structure` sections of `OBSIDIAN.md` and the matching `Vault root` line in the `ifs-session-writer` agent system prompt at `dotfiles/claude/agents/ifs-session-writer.md`. Both must agree.

## Setting up `IFS.md`

Copy `templates/IFS.md` from this directory into `<vault>/6 - Full Notes/IFS/IFS.md`. The minimum viable file is just the frontmatter:

```yaml
---
type: ifs_home
crisis_fallback: [[Crisis Plan]]
---
```

The Dataview blocks in the template are optional — they give you a live view of active parts, relationships, and unburdened parts on the homepage, but the skill doesn't read them. If you don't have the Dataview plugin installed, drop them.

## Setting up `Crisis Plan.md`

Copy `templates/Crisis Plan.md` from this directory into `<vault>/6 - Full Notes/IFS/Crisis Plan.md`, then **rewrite the body in your own words, in a clear non-crisis moment**. The template ships with two placeholder items so the shape is obvious; do not leave them as the entire content. The skill will never edit this page.

What "concrete" means here:
- 2–3 pre-committed actions you'll actually do, written in your own voice.
- Specific, not abstract. *"Text [name of person]"*, not *"reach out for support"*. *"20-min walk around the block"*, not *"do something physical"*.
- Things you can do alone if needed. The crisis plan is not a hotline and not a therapist.

The skill links to this page (via the `crisis_fallback:` wikilink in `IFS.md`) on two paths: a mood-step refusal at check-in, or an imminent-harm pattern match mid-session. In both cases the response is one line — *"Going to the crisis plan. [[Crisis Plan]]."* — and the session ends. What's on the page is what you read in the moment.

## Trailheads.md (optional)

If you want a phone-editable scratch list of unworked entry points to surface at the start of each session, create `<vault>/6 - Full Notes/IFS/Trailheads.md` as a flat dated bullet list. Format spec is in `../ifs-shared/OBSIDIAN.md`. If it doesn't exist, the skill treats it as empty — no error.

## When the skill refuses

| Refusal                                                                                                       | Fix                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `Can't run — 6 - Full Notes/IFS/IFS.md is missing or has no crisis_fallback: pointer.`                        | Create `IFS.md` from `templates/IFS.md`. Make sure the frontmatter includes `crisis_fallback: [[Crisis Plan]]`.              |
| `Can't run — crisis_fallback: points to [[<target>]] but that page doesn't exist.`                            | Create the page named in the wikilink. By default that's `Crisis Plan.md`; see `templates/Crisis Plan.md`.                   |

Both refusals end the session before any state is touched. Re-invoke `/em-ifs-session` once the missing file is in place.
