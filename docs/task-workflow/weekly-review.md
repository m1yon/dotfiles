# Run the Friday review

At 9am every Friday, a T3 Code scheduled task runs `/weekly-review` in a new thread. It drafts an answer for every step below and waits in that thread. It also adds a `weekly review` card to Today. Open the thread, and approve or fix the drafts. The job completes the card when it has applied your answers. See [AI jobs](ai-jobs.md#weekly-review).

To review by hand instead, follow these steps:

1. Empty the Inbox. See [Triage the Inbox](triage.md).
2. Look over your oldest cards that have no date, outside the Inbox and Someday. Give each one a date, move it to Someday, delete it, or leave it. A dated card stays off this list until its day.
3. Check each `@waiting` card. If the work is done, complete the card. If it's stuck, follow up or take it back.
4. Archive each feature project that shipped.
