# Triage the Inbox

Triage the Inbox once a day. If it's long, run `/triage-inbox` first. It drafts an answer for every card, and you approve or fix them.

Answer these questions for each card, in order:

1. **Actionable?** If not, delete it, move it to Someday, or put it in Obsidian.
2. **Under 2 minutes?** Do it now.
3. **Which Eisenhower quadrant?** Set the priority.
   - p1 Do. Urgent and important.
   - p2 Schedule. Important but not urgent.
   - p3 Delegate. Urgent but not important. Hand it to an agent or a person, and add `@waiting`.
   - Drop. Neither. Delete it.
4. **Where does it live?** Move p1 and p2 cards to their feature project, or to their area if they're one-offs. See [Todoist setup](todoist-setup.md#projects).

A card still at p4 hasn't been triaged.

If the Sentry digest card is in the Inbox, read it, add a card for each issue worth fixing, and complete the digest. The Sentry triage job reopens the same card when new issues arrive. See [AI jobs](ai-jobs.md).
